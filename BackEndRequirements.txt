Backend — StudyTools Local Program

    * Runs locally on the user's computer.

    * Maintains the local database.

    * Stores:
        * Homework
        * Notes
        * Subjects
        * Assessment results
        * Assessment weightings
        * Practice exams
        * HSC/ATAR data

    * Handles all calculations:
        * Subject percentages
        * Weighted averages
        * HSC estimates
        * ATAR estimates
        * Practice exam statistics

    * Handles adding, editing and deleting data.

    * Handles communication between the frontend and database.

    * Handles local file storage and configuration.

    * Handles the **highlight-to-homework** functionality.

    * Handles permissions required for interacting with the user's computer.

    * Provides an API/local connection for the frontend to communicate with the backend.

    * Can run without an internet connection.

    * Could later handle synchronisation between multiple devices.
